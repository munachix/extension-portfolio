# Permission justifications
**Single purpose:** adds borders/watermarks to the user's photos and resizes them for Instagram, offline.
| Permission | Justification |
|---|---|
| `storage` | Remembers the user's last look, saved looks and license status. |
| `sidePanel` | The app runs in Chrome's side panel. |
| Host: license server | Verifies a Pro license key (payments by Creem). Only the key and a random browser id are sent. |

No content scripts and no access to any website. Photos are processed locally and never transmitted. **Remote code:** none.
